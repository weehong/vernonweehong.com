## Design

All UI work follows the design spec in `docs/design/` exactly: read `docs/design/README.md` (hard rules and definition of done) before changing any page, component or style. Tokens are in `docs/design/theme.css` (Tailwind CSS v4, no `tailwind.config.js`), component classes in `docs/design/components.md`, routing, languages and content in `docs/design/pages.md`. If the spec does not cover something, extend the spec first.
